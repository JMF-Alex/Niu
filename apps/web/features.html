Under the hood

What happens when you push

Four stages, about 90 seconds on a first deploy and under a minute after that.

  1. 01 · Build

    Your code becomes a release

    We pull the commit, install dependencies with your lockfile and run your build script in a clean container.

  2. 02 · Provision

    The pieces it needs appear

    Database, environment variables and certificates are attached. Nothing to configure on later deploys.

  3. 03 · Release

    Traffic moves over safely

    The new release must answer a health check before it gets traffic. If it fails, the old one keeps serving.

  4. 04 · Watch

    We keep an eye on it

    Logs and metrics start streaming. If the app crashes, we restart it and send you an email.
