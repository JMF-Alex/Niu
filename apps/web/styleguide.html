Niu style guide

The single source for colours, type, spacing, motion and components. Every value is defined once in apps/web/src/styles.css.

Colour

Logo

An egg resting in a nest: a bowl, a rim and a dot, all on a 32 pixel grid. It is one colour and inherits the text colour, so it works on dark and light backgrounds. Keep at least 8px of clear space around it and never go below 16px.

Typography

Geist for everything, Geist Mono only for code and numbers. Weights 400, 500 and 600. No italics. Headings use tight negative tracking.

Motion

One curve

cubic-bezier(0.22, 1, 0.36, 1) in CSS, power4.out in GSAP. 500ms for movement, 300ms for colour.

GSAP and ScrollTrigger

Hero lines rise out of a mask, sections fade up 32px once, the tagline lights word by word, counters run on view.

Reduced motion

With reduced motion turned on, nothing moves. Content shows immediately and only colour changes remain.
